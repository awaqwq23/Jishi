## 隐私

- 政策正文：[privacy-policy.md](privacy-policy.md)。开发者公开联系邮箱已由本人提供：`820288706@qq.com`。
- “是否涉及个人信息收集”：是；不能因应用是普通效率工具而选择否。
- 功能用途：账号登录、云端保存与同步、个人记录、签到和积分、用户主动设置的系统提醒。
- 数据项：账号信息、电子邮件地址、用户主动上传的图片、用户文字内容；按平台现有分类另补 IP / 网络信息、应用使用或交互记录等与安全日志及业务流水对应的项目。固定数据项没有精确名称时选择最贴近的项并如实补充说明，不能虚构读取视频或整个相册。
- 跨境传输用途：当前数据部署在香港，需要按实际情况声明；不勾选不存在的广告营销、画像或 AI 生成用途。
- APP 类型信息：服务器不在中国大陆。只读实例元数据确认 Azure `eastasia`，微软区域列表将其定位为香港。
- 当前无自助注销接口；政策如实提供申请邮箱。发布前需要落实该邮箱的请求受理、身份核验及删除流程，不能承诺已经实现自助注销。
- 当前注册 / 原生首次启动没有完成隐私和境外数据处理所需告知、同意流程。政策正文不能代替这些功能。需要落实适用的数据传输及未成年人处理要求后再进行正式发布，不选择虚假的“已完成”答案。
- 资料发布可采用 AGC 隐私托管，或在已公开、可访问的网页展示同一正文。Git 内存在文档不等于政策已在应用内展示或获得用户同意。

## 内容分级

按问卷逐题回答，由华为根据回答计算年龄结果。不能直接以“正常软件”为依据手动承诺 3+、全年龄或已完成分级。下面是当前代码对应的事实，不替代未读取的具体题目。

| 分类 | 当前事实 / 答案依据 |
|---|---|
| 暴力、血腥 | 应用不提供此类内容：否 |
| 恐怖、惊吓 | 应用不提供此类内容：否 |
| 性、裸露、性暗示 | 应用不提供此类内容：否 |
| 不良语言 | 应用不提供辱骂或粗俗素材：否 |
| 烟酒、毒品和受管制物品 | 不提供相关内容、推广或交易：否 |
| 赌博、模拟赌博 | 没有：否 |
| 法定货币支付或兑换 | 没有内购、充值、付费开启、提现或现金兑换：否。个人积分兑换不是实际现金交易 |
| 法律与道德 | 不提供违法、仇恨、歧视、危险行为等内容：否 |
| 用户间交互 | 没有聊天、匹配、公开发布或用户间分享记录：否 |
| 用户信息收集 | 有邮箱、账号、用户记录、主动上传头像及网络安全信息：是；按后续题目细分 |
| 用户内容 | 用户可以输入私人文字和头像，其他用户无法浏览。若题目问能否创建内容应选是；若问能否公开发布或浏览其他用户内容则选否 |
| 开放网页 | ArkWeb 仅加载记时主站 / 备用站，不提供任意网页搜索浏览。不能把 Web 容器本身等同于开放互联网内容 |
| 金融 | 没有投资、证券、贷款、支付结算或真钱奖品：否 |
| AI | 不涉及生成合成服务 |

用户主动记录的私人文字不构成应用主动提供成人内容；也不能因此否认应用允许输入文字。详细选项需以 AGC 当前题目为准，最终结果应在问卷验证后核对并保存。
