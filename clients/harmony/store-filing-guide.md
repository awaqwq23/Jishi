# 鸿蒙 APP 备案申请指南（拾光记事）

整理日期：2026-10-20。本文说明中国大陆分发所需的 **APP 备案**，不是申请域名，也不是软件著作权登记。页面名称、材料格式以提交时的官方系统和所在地通信管理局要求为准。

状态：仓库记录仍为待办理，本次未登录备案后台查询、未提交申请。名称、包名和版本已核对本地源码及发布清单；主体、服务器、域名实名和既有备案状态需申请时再次确认。

## 1. 你应该按什么顺序办

1. **先确认受理渠道**：向实际接入商及华为开发者支持确认现有香港服务器方案如何办理。
2. **准备材料**：真实身份、联系信息、域名、服务器接入信息，以及鸿蒙包名、正式签名证书公钥和指纹。
3. **提交 APP 备案**：在能受理的平台填写资料，完成真实性核验、接入商初审、工信部短信核验和管局审核。
4. **备案成功后回华为后台校验**：备案信息与实际应用匹配后，继续提交应用上架审核。

APP 备案由主管部门审核，接入服务商或应用分发平台等按规定代提交。华为上架页中的备案信息校验不能代替取得正式备案结果。[工信部政策解读](https://www.miit.gov.cn/jgsj/xgj/hlwgl/art/2023/art_564bf0759d7e41d5b4aa8ce4996b9e84.html)、[华为分发指南](https://developer.huawei.com/consumer/cn/appgallery/devstart/)

## 2. 先解决香港服务器的受理问题

项目此前记录的服务器为 Microsoft Azure `eastasia`（中国香港），本次没有重新查询线上部署。

**不要直接购买服务器或照填大陆接入信息。** 华为云备案渠道要求符合条件的华为云中国大陆资源，现有 Azure 香港服务器不能直接作为该渠道的备案资源。应先获得受理答复，再决定是否购买资源或迁移真实业务。[华为云可备案服务器要求](https://support.huaweicloud.com/prepare-icp/icp_02_0003.html)

可以复制下面这段话向实际接入商咨询；上架侧的具体填报方式可通过[华为开发者支持](https://developer.huawei.com/consumer/cn/support/contactUs)确认：

> 我是中国大陆个人开发者，准备在华为应用市场上架鸿蒙应用“拾光记事”，鸿蒙包名 cn.jishi.todo。应用提供待办、日记、提醒和联网账号同步，服务器目前位于 Azure 中国香港，使用 jishi.awaqwq233.com 和 awaqwq233.com。请确认：能否受理该真实接入方案的 APP 备案？若不能，应通过什么合规渠道办理，需要哪些实际业务接入资源？已有主体备案时应新增 APP 还是变更已有记录？请同时告知鸿蒙公钥和证书指纹的填写格式。

网站位于香港与 APP 在中国大陆分发的备案要求是不同问题，不能用“香港网站无需网站备案”直接推导 APP 无需备案。请向华为说明实际主体和完整联网业务，确认适用流程。本项目有云端同步，不应仅因存在离线模式就把整个产品申报为纯单机应用，也不能把境内个人主体填成境外主体。

## 3. 需要准备哪些材料

| 材料 | 准备内容 |
|---|---|
| 主体身份 | 个人按系统要求提供本人有效身份证件；单位按要求提供营业执照、负责人证件及必要授权 |
| 联系信息 | 实际负责人手机号、邮箱、真实联系地址，确保能接短信和审核电话 |
| 域名材料 | 实际域名及子域名、域名实名认证信息，按要求提供域名证书 |
| 接入信息 | 实际服务商、地域、IP、可验证的备案资源，由受理渠道确认 |
| 应用信息 | 名称、图标、功能说明和服务类别 |
| 鸿蒙特征信息 | 包名、最终上架签名证书对应的公钥和指纹 |
| 其他材料 | 管局要求的承诺书、真实性核验材料及适用的前置审批文件 |

华为云备案图标当前要求不超过 100 KB，不要默认直接上传上架用的原尺寸大图。域名持有者需与备案主体一致；材料要求也会因省份不同而变化。[华为云 APP 备案准备说明](https://support.huaweicloud.com/prepare-icp/icp_02_0049.html)、[备案限制](https://support.huaweicloud.com/icprb-icp/icp_01_0008.html)

证件照片、身份证号、地址和验证码只在官方平台填写，不放进 Git 或公开素材。备案需要的是证书公钥和指纹，不需要上传 `.p12` 私钥文件、密码或生产密钥。

## 5. Windows 上如何获取公钥和指纹

使用**最终上架包对应的正式发布证书**，不要用调试证书、Android 证书、根证书或中间证书。

1. 登录[华为开发者官网](https://developer.huawei.com/consumer/cn/)，进入开发者中心 / AppGallery Connect，找到“拾光记事”对应应用。
2. 在“证书、APP ID 和 Profile”中找到“证书”，下载与正式包签名对应的发布证书。
3. 保留原文件，另存副本用于查看。若下载的是证书链，按官方图示仅保留应用的叶子证书；不确定时请开发人员核对，不凭证书块顺序猜测。
4. 在 Windows 打开该证书，进入“详细信息”，复制“公钥”和“指纹”。无需安装到系统受信任根证书库。
5. 按受理系统说明调整格式，例如是否去除空格和分隔符，完整粘贴后检查截断。

**华为云鸿蒙表单的“签名 MD5 值”允许填证书 SHA-1 指纹。** 这是该渠道字段的约定，并不表示两种算法相同。其他受理方按其鸿蒙规则填写。不要填 `.app` 安装包的 SHA-256 校验和。

官方步骤及 Windows 截图见[华为云：APP 特征信息及其获取方式（鸿蒙部分）](https://support.huaweicloud.com/usermanual-icp/zh-cn_topic_0000002085120221.html)。取得信息后，还要确认其与最终上架包的签名证书一致。

## 6. 正式申请的操作步骤

以下以**已确认满足受理条件的华为云渠道**为例。选择其他受理方时，使用其官方系统及资源规则。

### 第一步：进入备案系统

打开[华为云备案服务](https://www.huaweicloud.com/beian/index.html)，登录中国站实名认证账号，进入备案系统。华为开发者实名认证与 APP 备案是不同手续，完成前者不等于完成后者。

### 第二步：确认备案类型

- 主体和应用都没有备案：按首次备案办理。
- 已有网站或主体备案，新增该应用：按新增 APP / 新增互联网信息服务办理。
- 同一 APP 已有其他平台备案，缺鸿蒙：通过变更补充鸿蒙及对应特征信息。
- 更换接入商：另行确认新增接入及相关变更要求。

告诉系统或备案专员已有记录，以实际判断结果为准，不要为了加鸿蒙平台先注销现有备案。[备案流程](https://support.huaweicloud.com/usermanual-icp/zh-cn_topic_0000002127712329.html)、[多平台填写说明](https://support.huaweicloud.com/prepare-icp/icp_02_0049.html)

### 第三步：填资料并提交初审

填写主体及负责人信息，验证实际接入资源，添加 APP 服务信息，再填写鸿蒙包名、公钥和指纹。按系统要求上传材料、完成真实性核验并提交初审。接入商要求视频核验或补正时，按订单反馈办理。

“订单提交成功”和“初审通过”都不代表管局备案已经通过。

### 第四步：完成工信部短信核验

初审通过并上报后，留意负责人短信。按通知及时到[工信部备案系统](https://beian.miit.gov.cn/)完成核验，有效期以短信和系统提示为准，避免漏操作导致退回。

### 第五步：等待管局审核并核对结果

在订单查看进度及退回原因。华为云公开流程说明管局审核一般为 1—20 个工作日，补材料等环节可能增加总耗时，不保证固定日期拿号。

收到结果后，在工信部系统“公共查询”的 APP 备案查询中核对名称、主体、鸿蒙平台、包名及编号。[华为云首次备案流程](https://support.huaweicloud.com/usermanual-icp/zh-cn_topic_0000002581754184.html)

## 7. 备案成功后如何继续上架

1. 回到华为开发者中心该应用的上架信息，找到 APP 备案相关区域，按页面填入备案信息并校验。
2. 校验不通过时，对比备案记录与上架包的名称、主体、平台、包名、公钥、指纹，并按提示检查同步状态；不要随意重建应用或换包名。
3. 在应用显著位置展示真实备案编号，例如“关于”页面，并链接工信部备案系统；这项应用修改需另行实施和验证。
4. 继续完成华为要求的隐私、资质、分级、审核账号和正式包资料。备案通过不等于上架通过，也不代替软件著作权等适用资质。
5. 按实际业务和所在地要求核对公安联网备案等后续事项；它与本次工信部 APP 备案属于不同手续。

编号展示及后续事项见[华为云备案完成说明](https://support.huaweicloud.com/usermanual-icp/zh-cn_topic_0000002581754184.html)；上架资料见[华为提交应用指南](https://developer.huawei.com/consumer/cn/app/submit/)。
