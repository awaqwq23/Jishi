# Windows 客户端

修改 `app-config.json` 中的 `webUrl` 即可切换服务器。执行 `npm install && npm run build` 后，安装程序位于 `dist/`。

0.4.6 使用隔离的 preload 桥接系统通知，并把未来 21 天的提醒同步到 Electron 主进程。关闭主窗口后应用会驻留系统托盘以继续计时。

更新安装包使用八路 Range 分段下载，页面显示百分比、已下载大小、速度和剩余时间。未完成分段保存在应用专用目录，网络中断或进程结束后会在下次启动自动续传；完成 SHA-256 校验后才移动到系统“下载”目录。下载过程中托盘“退出”不会删除进度，而会返回窗口继续下载。
