# 安装包下载与更新修复记录

## 用户要求

用户反馈：客户端会显示新版本提示，但点击后无法下载安装包并完成更新，要求修复并更新服务器。

## 只读诊断

- 生产 `jishi-api`、`jishi-web`、`nginx` 均为 `active`。
- 根域名 `/note/updates/latest.json` 与独立 `jishi` 域名 `/updates/latest.json` 均返回 HTTP 200。
- Windows 0.4.5 与 Android 0.4.6 安装包在两个入口均返回 HTTP 200，Content-Length、服务器 SHA256、本地安装包及清单完全一致。
- 生产秘密文件通过存在、非符号链接、属主、600 权限和 `AUTH_SECRET` 非空门禁，未读取或输出秘密值。
- 最近 30000 条 Nginx 访问记录中没有客户端安装包 GET；故障发生在更新按钮点击后、网络下载请求发出前。

## 修复

- 更新按钮改为真实的同源下载链接，不再使用整页 `window.location.assign` 导航。
- 根据当前运行路径自动选择 `/downloads/` 或 `/note/downloads/`，不再强制从清单中的另一个域名下载。
- Nginx 下载目录增加 `Content-Disposition: attachment`，让 Electron、Android WebView 与浏览器明确进入文件下载流程。
- 保持 Windows 0.4.5、Android 0.4.6 版本和既有 API/清单字段不变；通过新的 Web `releaseId` 让已安装 0.4.x 客户端刷新兼容修复。
