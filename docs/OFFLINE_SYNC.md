# 拾光记事离线使用与同步

## 使用方式

- 进入应用时优先显示当前本机账号的数据，不等待服务器返回。
- 没有联网记录的新设备可以离线创建本机账号；已有云端账号可用相同邮箱和密码创建本机空间，恢复连接后仍须通过云端密码验证才能关联，密码不匹配时不会上传或覆盖云端数据。
- 已在本机登录的账号可以断网继续使用。退出后，使用本机保存的密码验证重新进入；其他账号的记录不会混入当前空间。
- 待办、分类、提醒组、计划、习惯、完成记录、日记、昵称、积分规则、签到和商品设置先写入 IndexedDB，再显示保存成功。窗口关闭、刷新及重启不会清空待同步操作。
- 窗口恢复焦点、网络恢复和每 30 秒都会尝试同步。页面显示本机保存、待同步数量或同步暂停原因。
- 同一条内容同时在云端和本机修改时保留本机内容并停止对应上传。可使用“备份本机内容”导出记录和待同步操作，备份不包含密码。不会整库替换云端数据。

## 积分及文件

离线积分显示本机预览，任务与习惯完成后的积分由服务器结算。离线签到保留实际日期，服务器支持补传最近 30 天的签到并避免重复奖励。兑换必须在联网且待同步操作完成后核对余额，不能在断网时宣称兑换成功。头像上传和批量导入需要联网；本机背景与外观继续可离线使用。

## 密码和账号隔离

本机密码以 AES-GCM 加密保存，使用不可导出的设备 CryptoKey；明文密码不写入 localStorage。旧版保存的明文密码缓存会清除。只有本机验证或恢复云端登录时在内存中解密。此机制不是系统密码保险箱，不能抵御已能执行应用代码或完全控制设备的人。

退出账号停止本机自动进入，但保留其记录和待同步操作。设置中的“清除本机保存的密码”只清除凭据，不删除业务记录；清除后再次离线登录无法验证，需联网重新登录并保存凭据。不要在共享设备使用本机账号功能。

## 原生入口与兼容

鸿蒙 0.3.6、Windows 0.4.10 和 Android 0.4.10 候选代码随包携带完整页面，在服务器失败时以原 HTTPS 站点地址提供本机页面。网络 API、Cookie、Origin 校验及各站点存储隔离继续有效，未放行 null Origin，也未开放文件来源访问原生提醒桥。

已安装旧版远程页面客户端需要至少成功加载一次新版 Web 并完成页面缓存，之后才能离线使用。新鸿蒙与 Windows 包支持首次启动断网进入。Android 0.4.10 候选包已编译，因缺少既有发布签名密钥，尚不能作为可覆盖安装的正式更新；正式 Android 清单暂保留已发布的 0.4.7。

不同站点（主域名与备用子域名）的本机存储受浏览器来源隔离；切换站点不会读取另一个站点的本机账号。恢复联网后可通过同一云端账号读取已上传数据。

- 浏览器真实验收：在隔离测试服务器不可达时创建账号和待办，关闭页面服务后刷新成功打开缓存页面并恢复内容，服务恢复后自动同步；测试服务器核实账号已创建且对应待办只有一条。
- 缓存回归：激活不等待页面导航、首次安装完整缓存 JS/CSS、静态文件失败不返回 HTML、保留不同作用域的缓存。

### 最终收尾验证

旧版已记住的密码先迁移为加密凭据，成功写入后才清除明文；原有自动登录意图保留。离线切换账号后会重新验证当前账号，写入同时核对服务器实际登录邮箱，防止旧 Cookie 造成记录串号。登录未通过后停止自动重试，避免反复触发登录限制。

补录保留事项、习惯的创建与完成时间。首次离线启用的积分支持最近 30 天补算；离线签到也支持最近 30 天补传。已有积分规则的修改在云端同步后生效，不改写之前已经生成的积分流水。

本机保存使用原子版本检查：另一页面更新后不会以旧快照覆盖待同步记录，界面保留未保存的输入并提示重新打开。已在真实浏览器验证保护提示、重启保留及联网后的单次上传。纯本机账号关联云端后，主题和本机背景继续保留；实际浏览器夜墨主题验证通过。

系统通知的修复、验证和真机检查见 [系统通知说明](SYSTEM_NOTIFICATIONS.md)。
