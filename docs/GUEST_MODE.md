# 游客模式与用户名注册

登录页提供“游客模式”，主页和个人中心会明确注明：所有游客记录只保存在当前设备，不上传服务器。游客编辑、签到、积分规则、兑换、头像及导出均在本机处理；网络恢复不会自动上传游客记录，退出和重启仍保留记录。清除浏览器或应用数据会删除本机记录，应使用“备份本机记录”定期备份。

选择“注册并同步游客记录”后，注册一个新用户名，输入并确认密码。用户名支持 2–32 位中文、英文字母、数字、下划线、短横线；忽略首尾空白和英文大小写。显示名称选填。老邮箱账号保留原账号密码登录能力，原接口和 Cookie 不变。

迁移包含待办（含回收站）、分类、提醒组、计划和习惯、完成记录、日记、个人资料、设置、签到、积分规则、完整积分流水和商品。记录标识与时间保留；同一批记录采用稳定迁移标识，在服务器一个事务中提交。失败不会留下半份数据，断网或丢失响应可以安全重试，完成后才使用云端快照。本机原游客备份保留至新建另一游客空间。

游客注册可在断网时先进入本机新账号，联网后完成注册和迁移。用户名被占用会恢复游客空间，提示更换用户名；登录已有账号不会把游客记录上传到该账号。云端已有内容时拒绝覆盖，本机记录继续保留。注册凭据以现有设备 AES-GCM 密钥加密保存，备份不包含密码。

游客积分与兑换是本机督促记录，注册后完整迁移；不是现金或付费权益。奖励由用户自行兑现。本机外观和背景图片继续属于设备设置，不上传服务器。

游客支持本机导出及完整备份；现有分区导入需要注册迁移后联网使用。整批迁移请求上限 8 MiB、每种记录上限 5000 条，超出时明确报错并保留全部本机数据，不截断上传。过期回收站条目的保留期在迁移时重新起算，避免服务器清理立即删除游客旧条目。
