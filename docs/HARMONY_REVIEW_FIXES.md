1. 用户指定新名称“拾光记事”，已同步应用级资源、Ability 标签、界面、通知文字、PWA 名称和商店介绍。鸿蒙版本 0.3.4 / 3000004，包名不变。

4. 独立审核账号已经通过正式 `/note/` 路径验证登录、bootstrap 均 200。私密登录资料在 `.local/review/AGC审核账号.txt`；不包含在 Git 或素材 ZIP 中。子域名复测需等待生产修复部署，AGC 审核字段仍需填入该账号。
